# AI: будущее, которого не существует

Доклад на два часа про экономику AI. Три года всем рассказывали, что LLM дешевле человека, а значит человек больше не нужен. Я сел и посчитал по отчётам самих компаний, что из этого сбылось. Получилось 93 слайда и один неудобный вопрос: покажите компанию, которая на этом реально заработала.

**Слайды:** https://iksergey.github.io/ai-future-that-does-not-exist/

Это один html-файл в ветке `site`, работает без интернета. Листать стрелками или пробелом, `F` — на весь экран.

**Откуда цифры:** [SOURCES.md](SOURCES.md), по каждому слайду.
